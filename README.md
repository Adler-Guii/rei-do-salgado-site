# Rei do Salgado — site em desenvolvimento

Versão pública de apresentação do novo site do **Rei do Salgado**, fabricante de salgados congelados de Rafard/SP.

## Conteúdo desta versão

- página inicial comercial;
- catálogo com cinco famílias de produtos;
- história e reportagens da marca;
- oportunidade para revendedores e deliveries;
- loja de Rafard e presença em diferentes cidades;
- contato direto com a equipe comercial.

Esta é uma versão de avaliação. Textos, imagens e informações comerciais ainda podem receber ajustes antes da publicação definitiva.
